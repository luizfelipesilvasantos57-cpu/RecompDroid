# RecompDroid v0.0.3 Release Notes

Release date: February 2025

## What's New in v0.0.3

- 🌍 **Multi-language Support**: Full offline on-device translation powered by ML Kit across 12 languages.
- ⭐ **Ratings & Reviews System**: Cloud Firestore-backed ratings and reviews with secure ownership verification.
- 📂 **Custom APK Picker**: Import any `.apk` file from phone storage to add to the library and install.
- 🔍 **Device Recomp Scanner**: Automatically detect installed recomp applications on the device.
- 🗑️ **System Uninstallation & Library Management**: System uninstallation with confirmation dialog and explicit library removal.
- 🧹 **Automatic APK Cleanup**: Automatically deletes temporary APK residue files 10 seconds after launching installation.
- 🔙 **Navigation Back Handling**: Standard system back button navigation stack across views and tabs.
- 🎮 **Console Filters & Sorting**: Platform/console filters in the Installed tab and sorting options across all views (Discover, Platforms, Installed).
