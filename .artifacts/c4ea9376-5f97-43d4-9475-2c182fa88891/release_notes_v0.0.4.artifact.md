# RecompDroid v0.0.4 (Versão de Testes / Beta)

Release date: February 2025

> [!CAUTION]
> **Versão de Testes (Beta)**: Esta é uma versão prévia/experimental destinada a testes. Podem ocorrer instabilidades ou comportamentos inesperados.

## Novidades na v0.0.4

- 🎮 **Filtro Standalone**: Novo filtro para exibir exclusivamente versões nativas standalone e engine ports de recompilação.
- 📱 **Seletor de Aplicativos do Dispositivo**: Escolha apps instalados diretamente no celular (excluindo sistema e ocultos) para adicionar à biblioteca.
- 🔄 **Pull-to-Refresh & Recarregamento Automático**: Atualize a página puxando para baixo e veja os apps adicionados refletidos instantaneamente.
- 🗑️ **Desinstalação Segura**: Diálogo de confirmação para desinstalação de pacotes do sistema com resolução inteligente de pacotes.
- 🌍 **Tradução Multilíngue & Avaliações**: Suporte a 12 idiomas via ML Kit e sistema de avaliações em nuvem com Firestore.

## 🤝 Procuramos Novos Ajudantes e Contribuidores!

O **RecompDroid** é um projeto de código aberto dedicado a trazer recompilações de console e ports nativos para o Android. Este aplicativo foi desenvolvido utilizando o **Android Studio** com auxílio de **Inteligência Artificial (IA)**.
